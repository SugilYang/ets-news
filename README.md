# 이티에스 산업신문 (ETS INDUSTRY DAILY)

이차전지 장비 · 전해액 주액 설비 · AMR 분야 뉴스를 **매일 아침 8시(KST)에 자동으로 모아**
신문 1면처럼 보여 주는 사내/대외 공개용 뉴스 포털입니다.

> **발행:** ETS(이티에스) · 충남 아산시 음봉면
> **분야:** 이차전지 제조장비 · 전해액 주액 설비 · AMR(자율주행로봇)

---

## 무엇을 하나요?

- **구글 뉴스**에서 우리 사업과 관련된 키워드로 기사를 자동 수집합니다.
- 아래 8개 섹션으로 편집해 신문 지면 형태의 웹페이지로 발행합니다.
  1. **종합 헤드라인** — 이차전지 장비 산업 주요 뉴스 (머리기사)
  2. **기업·고객사 동향** — 이티에스 / LG에너지솔루션 / 장비업계
  3. **안전·산업재해** — 배터리 공장 화재·산업안전·중대재해 *(빨강 강조)*
  4. **고용노동부·산업안전보건** — 정책·중대재해처벌법·근로환경
  5. **경제·산업 전망** — 이차전지 시황·투자·수주
  6. **AMR·스마트팩토리** — 자율주행로봇·물류자동화·스마트공장
  7. **글로벌 배터리** — 해외 공장·북미/유럽·공급망
  8. **기술 동향** — 전해액·전고체·차세대 배터리
- 매일 아침 8시에 **자동으로 최신 기사로 교체**됩니다. (GitHub Actions cron)
- 누구나 웹 주소로 접속해 볼 수 있습니다. (GitHub Pages)

기사 제목을 누르면 해당 언론사 **원문 기사**로 이동합니다. 기사 저작권은 각 언론사에 있습니다.

## 처음 한 번만 해 주세요 (GitHub Pages 켜기)

공개 웹주소로 보이게 하려면 **딱 한 번만** 설정하면 됩니다.

1. 저장소 상단 **Settings → Pages** 로 이동
2. **Build and deployment → Source** 를 **`Deploy from a branch`** 로 선택
3. **Branch** 를 **`main`**, 폴더는 **`/ (root)`** 로 지정 후 **Save**
4. 1~2분 뒤 공개 주소가 생성됩니다: `https://sugilyang.github.io/ets-news/`

이렇게 하면 사이트 최상위의 `index.html`(신문 지면)이 표시됩니다.

### 첫 발행 즉시 실행 (선택)

아침 8시까지 기다리지 않고 바로 갱신하고 싶다면:

1. 저장소 상단 **Actions** 탭 이동
2. 왼쪽 목록에서 **"매일 뉴스 자동 발행"** 선택
3. 오른쪽 **Run workflow** 버튼 클릭 → 1~2분 뒤 최신 기사로 갱신됩니다.

---

## 발행 시각에 대해

- 예약 시각은 `.github/workflows/daily-news.yml` 의 `cron: "0 23 * * *"` 입니다.
  (UTC 기준 23:00 = **한국시간 오전 8시**)
- GitHub 예약 실행은 서버 상황에 따라 **몇 분~수십 분 늦게** 실행될 수 있습니다. (GitHub 정책)
- 시각을 바꾸려면 위 cron 값을 수정하세요. 예) 오전 7시 → `0 22 * * *`

---

## 내용(키워드)을 바꾸고 싶다면

`scripts/feeds.py` 파일 하나만 고치면 됩니다. 코드를 몰라도 아래 부분만 바꾸면 됩니다.

- **섹션 추가/삭제/이름 변경**, **부제(tagline)**, **표시 개수(limit)**
- **검색어(queries)** — 이 단어들로 구글 뉴스를 검색합니다. (예: `"전해액 주액 설비"`)
- **신문 이름·회사 정보(SITE)** — 제호, 회사명, 위치 등

수정 후 Actions에서 **Run workflow** 를 누르면 바로 반영됩니다.

색상 강조는 각 섹션의 `accent` 값으로 조절합니다: `default | red | blue | green | gold`.

## 로컬에서 미리 보기 (개발자용)

```bash
pip install -r requirements.txt
python scripts/fetch_news.py      # public/index.html 생성
# public/index.html 을 브라우저로 열어 확인
```

> 사내망 등 외부 인터넷이 막힌 환경에서는 기사 수집이 되지 않아 안내용 카드가 표시됩니다.
> GitHub Actions(인터넷 접근 가능)에서 실행하면 실제 기사가 채워집니다.

## 폴더 구조

```
.
├── .github/workflows/daily-news.yml  # 매일 아침 8시 자동 실행(뉴스 수집→커밋)
├── scripts/
│   ├── feeds.py                      # 섹션·검색어·신문 정보 설정 (여기만 고치면 됨)
│   └── fetch_news.py                 # 뉴스 수집 + 신문 지면(HTML) 생성
├── public/
│   ├── index.html                    # 발행된 신문 지면 (자동 생성)
│   └── data/news.json                # 수집 결과 아카이브(JSON)
├── requirements.txt
└── README.md
```

## 참고 / 유의사항

- 기사는 **구글 뉴스에서 자동 수집**한 링크 모음이며, 본문 저작권은 각 언론사에 있습니다.
  지면에는 제목·언론사·시간만 표시하고, 원문 링크로 연결합니다.
- 특정 언론사의 크롤링 정책 변경 등으로 일부 기사가 누락될 수 있습니다.
  일부 검색이 실패해도 나머지 섹션은 정상 발행됩니다.
